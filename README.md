Show editable placeholders for Email, LinkedIn and GitHub. No backend contact form.



Design



Use a premium but simple developer portfolio design with a professional dark/light theme, subtle gradients, elegant typography, rounded cards, icons and smooth scrolling. Make it suitable for college placements and software engineering recruiters, not overly flashy.



Add a responsive navbar with Home, About, Skills, Projects, Education and Contact.



Use React + TypeScript + Tailwind CSS. Keep components reusable and code simple. Avoid unnecessary libraries and features.



IMPORTANT: Build the complete working portfolio now without asking unnecessary questions. Use placeholders for missing personal links, resume and project links so I can replace them later. Ensure everything works properly on mobile, tablet and desktop.
